# Introduction（论文引言草稿）

## 背景

热电制冷器（Thermoelectric Cooler, TEC）凭借无运动部件、双向可控、响应快的特点，在精密温控、激光二极管、电池热管理、可穿戴设备和航天载荷中被广泛使用。在户外或开放环境中，TEC 控温系统的散热端不是恒温的：环境温度、风速、相对湿度（湿表面蒸发散热）都会改变对流/辐射边界条件，从而改变被控对象的动态增益和稳态工作点。固定参数 PID 在出厂工况下整定良好，但在风掠突变、昼夜温差或湿表面蒸发强弱变化时，会出现超调增大、恢复变慢甚至振荡。

近年来深度强化学习（Deep RL）被用于 PID 在线整定：上层 PPO/SAC 每隔若干秒输出 (ΔKp, ΔKi, ΔKd)，下层 PID 闭环。但已有工作大多在集总一阶模型或固定扰动下验证，很少在带非线性散热（辐射 σT⁴、变对流系数、湿面蒸发）的二维对象上，把"直接 RL 控占空比"、"快环 RL 调增益"、"事件触发 RL 调增益"和传统 PID/bang-bang/增益调度放在同一个 benchmark 里公平对比，也很少报告 RL 在什么工况下才真正优于调好的 PID。

## 本文贡献

1. 一个开源的二维瞬态热仿真器（11×11 网格铜板，2×2 TEC 阵列），散热项包含辐射、Churchill-Chu 自然对流、风致对流和湿面蒸发（T>90°C 蒸干），覆盖 25→200°C 量程。
2. 七控制器统一 benchmark：fixed PID、bang-bang、staged（热惯性滑行）、gain-scheduled、PPO-direct、PPO-fast-PID（2 s 上层）、PPO-event-PID（10 s 死区触发），外加一个离散动作 PPO-bang-rl 作为对照。
3. 多扰动鲁棒性扫描：风速 0→3 m/s、RH 0→80%、环境温度阶跃、设定值阶跃。
4. 诚实报告：在慢、近线性、控制裕度大的对象上，RL 相对调好 PID 的标称提升只有 ~1%，但在强风掠扰工况下 MAE 改善 ~5%；ppo_direct 和 ppo_bang_rl 在本对象上失败。事件触发 RL 在线推理频率是快环的 1/5，策略网络 ~0.3M 参数，可上 MCU。
